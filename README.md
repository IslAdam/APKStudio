# Sait - HTML/CSS/JavaScript Website

A modern, clean website template built with HTML5, CSS3, and JavaScript.

## Getting Started

### Prerequisites
- A modern web browser
- Python 3+ (for development server) or any HTTP server

### Installation

1. Clone or download this repository
2. Navigate to the project folder

### Development

Start the local development server:
```bash
npm run dev
```

Or use Python's built-in server:
```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.

## Features

- Clean, semantic HTML5 structure
- Responsive CSS3 design

- Edit `index.html` to add your content
- Modify `css/style.css` for styling
